# Граф зависимостей Cargo

Практическая работа № 2, вариант 9. CLI читает INI и строит граф
прямых и транзитивных зависимостей рекурсивным обходом в глубину. Требуется Python 3.8+ со стандартной библиотекой.

## Сборка, запуск и тесты

Команды из корня репозитория:

```sh
python3 -m compileall -q src
./run.sh examples/cargo.ini
python3 -m unittest discover -s tests -v
```

## Параметры секции graph

| Ключ | Значение |
| --- | --- |
| package | Имя пакета Cargo, в тестовом режиме — заглавные латинские буквы. |
| repository | HTTP(S)-адрес sparse-индекса Cargo или путь от INI к тестовому файлу. |
| test_mode | true для файла, false для сети. |
| image | Имя будущего изображения с расширением .svg. |
| exclude | Подстрока имени пакета. Пустое значение отключает фильтр. |

Все пять ключей обязательны. В сетевом примере корневой пакет — serde_json. Тест поочерёдно подставляет неверное имя, адрес, режим,
расширение и удаляет обязательный ключ exclude. CLI сообщает ошибку в stderr
и завершает работу с ненулевым кодом.

## Данные Cargo

Программа по HTTP читает JSON-строки sparse-индекса. Для каждого имени
используется последняя опубликованная неотозванная запись. Учитываются все
объявленные зависимости, включая optional, build, dev и целевые платформы.
Псевдонимы разворачиваются в имена пакетов, повторы удаляются.
Это граф объявлений по именам пакетов, без разрешения ограничений версий Cargo.

## Локальный граф и примеры обхода

Запустите `./run.sh examples/local.ini`. Файл graph.json задаёт каждый
пакет отдельным ключом, а его прямые зависимости — массивом имён.
Даже лист должен иметь запись с пустым массивом. Результат:

```text
A: B C
B: D
D: B
C: D
```

Порядок строк соответствует первому посещению в DFS. Ребро D → B замыкает
цикл, а D встречается в двух ветвях. Каждая вершина раскрывается один раз.

* Задайте `exclude = B` в копии INI рядом с оригиналом. Получатся строки
  `A: C`, `C: D`, `D:`. Фильтр учитывает регистр и отсекает всю ветвь,
  если до её потомков нет другого пути.
* Задайте `package = E` с пустым exclude. Результат — одна строка `E:`.
* При совпадении фильтра с корнем вывод пуст.

Параметр image зарезервирован для последующего этапа визуализации.
