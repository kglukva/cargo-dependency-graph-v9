# Граф зависимостей Cargo

Практическая работа № 2, вариант 9. CLI читает INI и печатает прямые зависимости
заданного пакета (по одному имени на строку). Требуется Python 3.8+ со стандартной библиотекой.

## Сборка, запуск и тесты

Команды из корня репозитория:

```sh
python3 -m compileall -q src
./run.sh examples/cargo.ini
python3 -m unittest discover -s tests -v
```

## Функции

| Функция | Назначение |
| --- | --- |
| settings.check_source | Проверяет URL индекса или существование локального файла. |
| settings.check_url | Проверяет схему, адрес, порт и отсутствие лишних частей URL. |
| settings.check_text | Отклоняет управляющие символы в параметрах. |
| settings.check_image | Проверяет расширение, каталог и доступ для записи изображения. |
| settings.load_settings | Читает INI, проверяет пять ключей, возвращает настройки и режим. |
| registry.index_path | Вычисляет путь записи пакета в sparse-индексе Cargo. |
| registry.dependencies | Читает индекс, раскрывает псевдонимы и возвращает прямые зависимости. |
| main.run | Получает и печатает прямые зависимости пакета. |
| main.main | Разбирает аргумент командной строки, сообщает ошибки и код завершения. |

Пути repository и image отсчитываются от каталога INI. Каталог изображения
должен существовать и быть доступен для записи. Проверка image выполняется
без создания файла. Строка exclude допускает пустое значение и любые печатные
символы. Управляющие символы отклоняются для всех пяти параметров.

## Параметры секции graph

| Ключ | Значение |
| --- | --- |
| package | Имя пакета Cargo, в тестовом режиме — заглавные латинские буквы. |
| repository | HTTP(S)-адрес sparse-индекса Cargo или путь от INI к тестовому файлу. |
| test_mode | true для файла, false для сети. |
| image | Имя будущего изображения с расширением .svg. |
| exclude | Подстрока имени пакета. Пустое значение отключает фильтр. |

Все пять ключей обязательны. Для serde_json среди результатов есть `itoa`. Тест поочерёдно подставляет неверное имя, адрес, режим,
расширение и удаляет обязательный ключ exclude. CLI сообщает ошибку в stderr
и завершает работу с ненулевым кодом.

## Данные Cargo

Программа по HTTP читает JSON-строки sparse-индекса. Для каждого имени
используется последняя опубликованная неотозванная запись. Учитываются все
объявленные зависимости, включая optional, build, dev и целевые платформы.
Псевдонимы разворачиваются в имена пакетов, повторы удаляются.
Это граф объявлений по именам пакетов, без разрешения ограничений версий Cargo.
